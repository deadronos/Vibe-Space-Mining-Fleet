## Who owns what

- **git** tracks everything outside `Vibe-Space-Mining-Fleet/`, including `web/public/unity/`.
- **UVCS** tracks `Vibe-Space-Mining-Fleet/` (Assets, Packages, ProjectSettings). Repository `Vibe-Space-Mining-Fleet/Vibe-Space-Mining-Fleet@iridanblub@unity`.
- GitHub issues and PRs cover both halves. A PR for Unity-only work carries notes in `documentation/issues/` that name the UVCS branch and changeset. See [issues-and-decisions.md](issues-and-decisions.md).

## Where the code runs

- The sim (`FleetSim`) is plain C#, ticked at a fixed 20 Hz by `FleetSimRunner`; views interpolate between ticks. Read [decisions/0001-deterministic-fixed-tick-sim.md](decisions/0001-deterministic-fixed-tick-sim.md) before touching it.
- The scene is generated by `MiningFleetSceneBuilder` (menu **Space Mining Fleet**). Change the builder, then rebuild the scene; don't wire objects by hand.
- The browser page owns the toolbar, saves (localStorage) and file export/import. Unity owns the game and its in-canvas HUD.
